O que estamos analisando?

Esta página apresenta uma análise exploratória dos dados (EDA). O objetivo é compreender a composição da base, identificar padrões e levantar hipóteses antes de aplicar os algoritmos de Machine Learning.

Importante

Os gráficos representam os dados observados, não previsões. Correlação indica associação entre variáveis, mas não comprova uma relação de causa e efeito.

02 · RELACIONAMENTO ENTRE DADOS

Matriz de correlação

Identifique quais características apresentam comportamentos semelhantes ou opostos.

Como interpretar os valores?
  • Próximo de +1: associação positiva.
  • Próximo de 0: pouca associação linear.
  • Próximo de -1: associação negativa.

Quanto mais próximo dos extremos, mais forte é a associação linear.

Principais relações encontradas

A matriz utiliza o coeficiente de Pearson entre variáveis numéricas. Identificadores, datas e categorias não participam desse cálculo.
